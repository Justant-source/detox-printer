# 실험 기록

> 형식: 실험 하나당 3줄. 보낸 것 / 관찰 / 결론.
> 성공 여부와 무관하게 전부 남긴다. 실패 기록이 이 프로젝트의 자산이다.

| 항목 | 값 | 확인 방법 |
|---|---|---|
| VID:PID | (미확인) | 1단계 |
| BULK OUT 엔드포인트 | (미확인) | 1단계 |
| wMaxPacketSize | (미확인) | 1단계 |
| 인터페이스 클래스 | (미확인) | 1단계 |
| 초기화 시퀀스 | (미확인) | 2단계 |
| **WIDTH_BYTES** | (미확인) | 3단계 실측 |
| 검정 비트값 (1 or 0) | (미확인) | 4단계 |
| 블록당 최대 라인 수 | (미확인) | 4단계 |
